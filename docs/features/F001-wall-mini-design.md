# F001 收藏墙 · mini design.md（V1 视觉意图 + 核心 Token + 执行约束）

> Status: draft，V2 视觉方向已定（杂志编辑风），字体阶梯/版式节奏/封面处理见下方深化章节
> 配套：`F001-wall-ux-spec-draft.md`（功能/边界）、`my-craft.md`（个人偏好归档，视觉方向拍板记录在此）

## V1 视觉意图（2026-07-13 修订：升级为杂志编辑风）

- **气质**：从"克制工具墙"升级为**杂志编辑风**（cy 2026-07-12 三选一拍板，理由待后续实机反馈补充）——工具不再是网格里等权重的卡片，而是被"编排"过的内容条目，像一本工具类杂志的内页，而不是一张数据表格。**关键原则：杂志感来自排版结构和字阶层级，不靠堆色彩**——色彩基调延续下面"色温"条不变。
- **密度**：保留中高密度基本盘，但引入"主次节奏"——精华区首条做放大的 hero 展示，其余降级为常规卡片，制造视觉焦点，避免纯网格的单调感（详见"版式节奏"）。
- **色温**：不变，中性冷灰基调延续；强调色仍然克制，只用于分区规则线、序号、hover，不做大面积色块。
- **语言**：中文优先不变；新增一套"编辑体"文字标签语汇——eyebrow（小标签）、kicker（分类序号）、deck（引导句），是杂志排版的核心识别符号，取代原来"一句话定位"和分类标签视觉上无差别的处理。
- **参考方向**：`xiaoer-artstudio-design`（日式编辑风）留作后续细化输入，本版基于通用杂志编辑排版惯例（强字阶对比、栏目规则线、统一图片处理）先出 v1，不等该仓库拆解完成。

## 杂志编辑风视觉规格 v1

### 字体阶梯（Type Scale）

杂志排版靠字阶**跳跃对比**，不是线性递增。在现有 `--font-size-*` token 基础上新增两级：

| 层级 | 变量名 | 用途 | 说明 |
|---|---|---|---|
| Display | `--font-size-display`（沿用） | 页面大标题"收藏墙" | 字重可从 700 提到 800，加大与其他层级的对比 |
| Headline | `--font-size-card-title`（沿用） | 卡片标题 | 字重同步提到 700，与 deck/body 拉开差距 |
| **Deck**（新增） | `--font-size-deck` | 卡片"一句话定位"字段 | 独立于 body，介于 headline 和 body 之间；这是当前设计缺的一级——现在 headline 和一句话定位视觉上太接近，编辑感弱 |
| Body | `--font-size-body`（沿用） | 正文/说明 | 不变 |
| **Eyebrow**（强化） | `--font-size-caption` + `--tracking-eyebrow`（新增字距变量） | 分类标签、section 小标题 | 现有 `.eyebrow` class 只调了颜色和字号，杂志感要靠**字距拉宽**（`letter-spacing`）+ 全部大写/等效处理强化识别度 |

### 版式节奏（Layout Rhythm）

- **分区规则线**：每个 section（常用精华 / 最近收藏）顶部加一条细分隔线，线上方放 section 序号（如"01 / 常用精华"），呼应杂志目录页的栏目分隔语言——不是新增视觉噪音，是把现有 `--color-border` 细边框原则用在 section 层级，而不只是卡片层级。
- **主次卡片**：精华区第一条做 hero 卡片——跨两列宽度、更大的封面高度、Headline 用 Display 级字号；精华区其余条目和最近收藏区维持常规卡片尺寸。这是"主次节奏"在网格里的具体落地，取代当前所有卡片等大的排列。
- **编号感**：卡片可选加"条目编号"（01, 02...），强化"这是编辑过的精选顺序"而非随手罗列的数据表格。编号只在精华区使用，最近收藏区不加（避免和"最近"的时间序列语义冲突）。
- **留白节奏**：section 之间的间距要比卡片内部间距高一档——现有 `--spacing-xl` 已够用，但当前用法和卡片内 `--spacing-md` 差距不够大，建议 section-to-section 间距再拉开，制造"呼吸感"。

### 封面处理（Cover Treatment）

这是杂志感最容易失手的一环——当前封面是不同来源截图直接拼贴，尺寸、色调、构图各异，观感杂乱：

- **统一宽高比**：新增 `--cover-ratio`（建议 4:3 或 16:10，二选一，交喵喵按现有 653 条封面图实际尺寸分布定），替代当前固定高度裁切，减少"胡乱截屏"感。
- **统一色彩处理**（可选，视觉预算允许再做）：给封面图加一层轻度统一滤镜（如统一降低饱和度 10-15% 或叠一层极淡色罩，走 `--cover-tone` token），让不同来源截图在视觉上更接近同一套"编辑过的图库"，而不是原始截图直接拼贴。这条如果一期实现成本高可以先跳过，不阻塞上线。
- **Hover 处理**：图片改用"跨页缩放"感——`scale(1.03)` 而不是当前卡片整体的位移（`translateY`），封面和卡片信息区的 hover 反馈分离，更像杂志图片的微交互而不是"按钮被按下"的反馈。
- **无封面兜底**：延续现有分类图标兜底方案，但外框加一圈细边框 + 可选编号，让它在视觉上"属于这一期杂志"，而不是明显的"数据缺失占位"。

## 核心 Token 表

| 类别 | 变量名 | 用途 |
|---|---|---|
| 颜色 | `--color-bg` | 页面背景（浅灰白；深色模式走 `data-theme` 切换，不另编第二套值） |
| | `--color-surface` | 卡片背景 |
| | `--color-border` | 卡片/分区描边（细边优先于阴影，符合"厚容器不如细边框"的克制原则） |
| | `--color-text-primary` / `--color-text-secondary` | 主/次文字 |
| | `--color-brand` | 唯一强调色，用于 hover/active/精华区标记，克制使用 |
| | `--color-badge-frequent` / `-common` / `-occasional` / `-new` | 对应 ⭐高频/📦常用/🔍偶尔/🆕待试 四种状态语义色 |
| 间距 | `--spacing-xs/sm/md/lg/xl` | 4/8/16/24/32px 阶梯 |
| 字体 | `--font-cn` | 中文字体栈，系统默认中文字体优先 |
| | `--font-size-title` / `-body` / `-caption` | 标题/正文/说明文字字号 |
| 形状 | `--radius-card` | 卡片统一小圆角，不做过度圆润 |
| | `--shadow-card` | 极轻阴影，默认不明显，hover 时略加深 |
| 动效 | `--duration-hover` | ≤200ms，遵 craft.md 动效克制规则，仅动 `transform` |
| 字体（V2 新增） | `--font-size-deck` | "一句话定位"字段专用字号，介于 headline 和 body 之间 |
| | `--tracking-eyebrow` | eyebrow/kicker 标签字距，拉宽制造编辑体识别度 |
| 封面（V2 新增） | `--cover-ratio` | 封面统一宽高比，替代当前固定高度裁切；具体比例（4:3 或 16:10）待喵喵按现有封面图实际尺寸分布定 |
| | `--cover-tone`（可选） | 封面统一色调滤镜强度，视觉预算允许再接入，不阻塞上线 |
| 版式（V2 新增） | `--rule-width` | section 分区规则线粗细，延续"细边优先于阴影"原则 |

## 执行约束

- 所有视觉取值必须引用上表变量，**禁止硬编**颜色值/像素值。
- 缺失的 token：先用最接近的现有档位顶上，把缺口记进 `gaps.log`（待建），不许现编一个新值。
- 反模式黑名单（继承 AI Slop 表）：禁蓝紫渐变、禁玻璃态滥用、禁等大白卡、禁 Inter 起手（中文场景默认中文字体）、禁 bounce 弹跳动效。
- CSS 变量占位阶段：`site/` 脚手架建成后，先把上表变量落进 `:root`，UI 开发直接引用；正式配色数值（十六进制等）待视觉细化时再定，本版只锁变量名和用途，不锁死具体色值。
- **V2 迁移节奏**：字体阶梯（Deck/Eyebrow 强化）+ 版式节奏（分区规则线/hero 卡片/编号）是本轮迭代范围；封面统一色调滤镜（`--cover-tone`）视觉预算不够可以推迟，不阻塞第三轮迭代收口。`xiaoer-artstudio-design` 的细化参考、kimi 整理的 26 条 AI Slop 反模式清单到位后，可再出一版视觉审计，本版不等它们。
